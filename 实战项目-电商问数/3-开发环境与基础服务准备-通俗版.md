## 二、uv 是什么？为什么要用它？

**uv** 是一个 Python 项目管理工具，把"创建环境、安装依赖、锁定版本"这些事统一到了一套命令里。

和传统方式对比：

| 传统方式 | uv 方式 |
|---------|--------|
| venv 创建环境 + pip 安装依赖 | `uv init` + `uv add` 一把梭 |
| 手动维护 requirements.txt | 自动维护 pyproject.toml + uv.lock |
| 依赖版本容易飘 | uv.lock 锁定精确版本 |

### 最常用的三个命令

```bash
uv add 包名      # 添加依赖
uv remove 包名   # 删除依赖
uv sync          # 把项目依赖一次性装齐
```

> `uv add` 像"往购物车里加东西"，`uv sync` 像"一键结账，把购物车里的全买了"。

### 创建项目

```bash
uv init shopkeeper-agent    # 初始化项目
cd shopkeeper-agent
uv venv                     # 创建虚拟环境
```

### 安装依赖

```bash
uv add fastapi[standard] sqlalchemy asyncmy qdrant-client "elasticsearch[async]>=8,<9" langchain langchain-huggingface langgraph jieba omegaconf pyyaml loguru python-dotenv
```

不用死记每个包，先知道它们分几类：

| 类别 | 包 | 作用 |
|------|---|------|
| 后端框架 | fastapi | Web 服务 |
| 数据库 | sqlalchemy, asyncmy | 数据库访问 |
| 检索 | qdrant-client, elasticsearch | 向量检索 + 全文检索 |
| AI | langchain, langgraph, langchain-huggingface | 智能体编排 |
| 工具 | jieba, omegaconf, pyyaml, loguru | 分词、配置、日志 |

## 三、用 Docker 启动基础服务

项目需要这些服务：

| 服务 | 作用 | 端口 |
|------|------|------|
| MySQL | 元数据库 + 数仓模拟 | 3306 |
| Qdrant | 向量数据库 | 6333 |
| Elasticsearch | 全文检索 | 9200 |
| Kibana | ES 调试界面 | 5601 |
| TEI (Embedding) | 文本转向量 | 8081 |

### 启动前：先下载 Embedding 模型

这一步容易漏掉！模型文件需要单独下载：

```bash
uv run hf download BAAI/bge-large-zh-v1.5 --local-dir docker/embedding/bge-large-zh-v1.5
```

### 一键启动所有服务

```bash
cd docker
docker compose up -d
```

第一次启动会比较慢（要下载镜像），之后就很快了。

启动后可以在 Docker Desktop 里看到所有容器都在运行。

## 四、遇到问题怎么办？

### Docker 拉镜像失败

最常见的原因是网络问题。两种解决思路：
1. 配置镜像加速
2. 配置代理

### 服务启动后怎么验证？

| 服务 | 验证方式 |
|------|---------|
| MySQL | 用 Navicat/DBeaver 连接 localhost:3306 |
| Qdrant | 浏览器打开 http://localhost:6333/dashboard |
| ES | 浏览器打开 http://localhost:5601 |
| Embedding | 浏览器打开 http://localhost:8081/docs |
