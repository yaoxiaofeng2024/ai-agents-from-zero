# 第十六章（通俗版）：查询接口实现——把假接口换成真的

---

## 一、这一章做什么？

把第 15 章的 `fake_streamer()` 替换成真实的问数智能体。

最终调用链路：

```text
前端 POST /api/query
  → query_router 接收请求
  → Depends(get_query_service) 获取 QueryService
  → QueryService.query() 调用 LangGraph 工作流
  → StreamingResponse 按 SSE 格式流式返回
```

---

## 二、代码文件分工

| 层次 | 文件 | 一句话 |
|------|------|--------|
| 入口层 | `main.py` | 创建应用，挂路由 |
| HTTP 层 | `query_router.py` | 接请求，返流式响应 |
| 业务层 | `query_service.py` | 调工作流，组织 SSE 消息 |
| 依赖层 | `dependencies.py` | 组装 Service、Repository、Session |
| 生命周期 | `lifespan.py` | 初始化和关闭外部客户端 |

**记住一句话：main 挂路由，router 接请求，service 调工作流，dependencies 组装对象，lifespan 管资源。**

## 三、入口和路由：让 HTTP 请求先进来

### main.py

```python
app = FastAPI(lifespan=lifespan)  # 注册生命周期
app.include_router(query_router)   # 挂载路由
```

### query_router.py

```python
@query_router.post("/api/query")
async def query_handler(
    query: QuerySchema,
    query_service: Annotated[QueryService, Depends(get_query_service)],
):
    return StreamingResponse(
        query_service.query(query.query),
        media_type="text/event-stream",
    )
```

路由层只做三件事：接请求体、拿 Service、返回流式响应。**路由层越薄越好。**

## 四、QueryService：把一次请求变成一次图执行

### 为什么需要 QueryService？

如果不抽出 Service，路由函数里会堆满：创建 State、创建 Context、调图、包 SSE、处理异常……路由层既懂 HTTP 又懂工作流，边界就乱了。

抽出 Service 后：

```text
query_router → 只管 HTTP
query_service → 只管业务
```

### 核心代码

```python
class QueryService:
    def __init__(self, meta_mysql_repository, embedding_client,
                 dw_mysql_repository, column_qdrant_repository,
                 metric_qdrant_repository, value_es_repository):
        # 保存所有依赖
        ...

    async def query(self, query: str):
        # State：任务数据（会变）
        state = DataAgentState(query=query)

        # Context：工具资源（拿来用）
        context = DataAgentContext(
            column_qdrant_repository=...,
            embedding_client=...,
            ...
        )

        try:
            async for chunk in graph.astream(input=state, context=context, stream_mode="custom"):
                yield f"data: {json.dumps(chunk, ensure_ascii=False, default=str)}\n\n"
        except Exception as e:
            error = {"type": "error", "message": str(e)}
            yield f"data: {json.dumps(error, ensure_ascii=False, default=str)}\n\n"
```

### State vs Context

| | State | Context |
|--|-------|---------|
| 存什么 | 业务中间结果 | 运行时工具 |
| 例子 | keywords、sql、result | Repository、Client |
| 特点 | 执行过程中会变 | 节点执行时拿来用 |

**不要把 Repository、Client 塞进 State。**

### 为什么异常也要包装成 SSE？

流式响应一旦开始写出，HTTP 响应头已经发出去了，不能改状态码。所以把异常也包成一条 SSE 消息，前端按 `type=error` 处理。

## 五、dependencies.py：把对象创建交给依赖层

### 依赖树

```text
get_query_service
  → get_meta_mysql_repository → get_meta_session
  → get_dw_mysql_repository → get_dw_session
  → get_embedding_client
  → get_column_qdrant_repository
  → get_metric_qdrant_repository
  → get_value_es_repository
```

### 和 lifespan 的配合

```text
lifespan.py → 应用启动时初始化客户端管理器
dependencies.py → 每次请求中取出客户端或 Session，组装 Repository 和 Service
```

### MySQL Session：请求级资源

```python
async def get_meta_session():
    async with meta_mysql_client_manager.session_factory() as session:
        yield session  # 请求期间使用
    # 请求结束后自动关闭
```

### Repository 组装

```python
async def get_meta_mysql_repository(
    session: Annotated[AsyncSession, Depends(get_meta_session)],
):
    return MetaMySQLRepository(session)
```

### 最终组装 QueryService

```python
async def get_query_service(
    meta_mysql_repository: Annotated[...],
    embedding_client: Annotated[...],
    dw_mysql_repository: Annotated[...],
    column_qdrant_repository: Annotated[...],
    metric_qdrant_repository: Annotated[...],
    value_es_repository: Annotated[...],
) -> QueryService:
    return QueryService(
        meta_mysql_repository=meta_mysql_repository,
        embedding_client=embedding_client,
        ...
    )
```

## 六、lifespan.py：应用级资源管理

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    # 启动时初始化
    qdrant_client_manager.init()
    embedding_client_manager.init()
    es_client_manager.init()
    meta_mysql_client_manager.init()
    dw_mysql_client_manager.init()

    yield  # 应用运行中

    # 关闭前释放
    await qdrant_client_manager.close()
    await es_client_manager.close()
    await meta_mysql_client_manager.close()
    await dw_mysql_client_manager.close()
```

## 七、本章要点速记

| 要点 | 一句话 |
|------|--------|
| QueryService | 把 HTTP 请求转成一次 LangGraph 图执行 |
| State vs Context | State 放业务数据，Context 放运行时工具 |
| dependencies.py | 按层次组装底层对象，路由不关心细节 |
| lifespan.py | 管理应用级资源的初始化和释放 |
| Session | 请求级资源，用带 yield 的依赖管理 |
| 异常兜底 | 流式响应中异常也包成 SSE 消息 |
